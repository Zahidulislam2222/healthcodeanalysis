# Support

| Need | Where |
|---|---|
| Bug report | [Open a bug issue](../../issues/new?template=bug_report.yml) |
| Feature idea | [Open a feature request](../../issues/new?template=feature_request.yml) |
| Security vulnerability | **Private:** follow [SECURITY.md](SECURITY.md). Never use a public issue |
| Setup and usage questions | [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md), then open an issue |
| Hiring or client enquiries | Contact the maintainer through the GitHub profile |

This is a single-maintainer project. Responses are best-effort; there is no guaranteed support SLA.

**This project does not provide medical advice.** Do not send medical questions or patient information. See the [medical disclaimer](docs/legal/MEDICAL-DISCLAIMER.md).
